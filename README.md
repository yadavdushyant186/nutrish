# Nutrish — Artisanal Dry Fruits & Superfood Seeds

A modern, responsive e-commerce storefront for **Nutrish**, an artisanal direct-to-consumer brand offering single-origin dry fruits and raw superfood seeds in Indian Rupees (INR).

---

## 🌿 Overview

Nutrish brings farm-fresh, cold-stored, unbleached nuts and raw seeds directly to consumers. The storefront is designed with an organic, warm editorial aesthetic using Tailwind CSS, Playfair Display typography, and Lucide icons.

### Key Highlights:
- **Zero Build Step**: Pure HTML5, modern Tailwind CSS, and vanilla JavaScript. Ready to host anywhere (GitHub Pages, Netlify, Vercel).
- **Interactive Jar (Cart)**: Dynamic slide-out cart drawer with free express shipping milestone tracker (above ₹999), weight selector options, and live pricing calculations.
- **Product Catalog**: Single-origin Mamra Almonds, W240 Cashews, Kashmiri Walnuts, Pistachios, Chia Seeds, Flax Seeds, Pumpkin & Sunflower seeds.
- **Responsive Design**: Flawless experience across mobile phones, tablets, and wide desktop screens.

## 🚀 Live Demo on GitHub Pages

3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
